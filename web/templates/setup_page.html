Client setup

Each client exports OpenTelemetry to the ai-usage OTLP receiver. Start the receiver with --otlp-http 127.0.0.1:4318 (or AI_USAGE_OTLP_HTTP_ADDR), then configure a client below. The snippets update as you edit the receiver settings.

{{range .Setup.Agents}}{{.Name}} {{end}}
{{if eq .Setup.Agent "claude-code"}}

Claude Code

Claude Code has built-in OpenTelemetry support configured through environment variables. Add them to the env block of ~/.claude/settings.json so every session exports:

{{template "setup-snippet" "claude-code-settings"}}

Leave OTEL_LOG_USER_PROMPTS and OTEL_LOG_TOOL_DETAILS unset. Logs are exported every 5 seconds by default (OTEL_LOGS_EXPORT_INTERVAL, in milliseconds). A positive reported cost_usd is used as-is; otherwise the local pricing fallback estimates the cost. Reasoning tokens are not reported and show as unknown.

{{else if eq .Setup.Agent "opencode"}}

OpenCode

OpenCode exports telemetry through the third-party @devtheops/opencode-plugin-otel plugin. Add it to ~/.config/opencode/opencode.json:

{{template "setup-snippet" "opencode-config"}}

Export the header before starting OpenCode:

{{template "setup-snippet" "opencode-token"}}

Leave optional prompt capture disabled. The plugin may emit content-bearing span attributes; ai-usage reads only its usage-field allowlist and never stores them. Reported costs take priority.

VS Code GitHub Copilot

Copilot Chat has native OpenTelemetry support. Add this to the VS Code user settings.json:

{{template "setup-snippet" "copilot-settings"}}

The default endpoint is http://localhost:4318, so a local receiver needs nothing else. For any other receiver, start VS Code with the standard OTLP variables:

{{template "setup-snippet" "copilot-env"}}

Keep captureContent at its false default. COPILOT_OTEL_PROTOCOL selects otlp-http (the default) or otlp-grpc. Copilot does not report a cost; ai-usage estimates one when pricing is available.

Maki

Maki has built-in OTLP telemetry. Add the telemetry table to init.lua:

{{template "setup-snippet" "maki-config"}}

Keep the token out of a committed init.lua. Leave log_user_prompts and log_tool_details disabled. Maki reports no reasoning-token count or subagent identifier, so reasoning shows as unknown.

After a request, check its requests. If nothing arrives, the Stats page shows whether telemetry was received, rejected or ignored.

For gRPC, start ai-usage with --otlp-grpc 127.0.0.1:4317 and point the client at port 4317 with its gRPC protocol. Full notes are in docs/client-setup.md.

{{- if eq . "claude-code-settings"}}
{
  "env": {
    "CLAUDE_CODE_ENABLE_TELEMETRY": "1",
    "OTEL_LOGS_EXPORTER": "otlp",
    "OTEL_METRICS_EXPORTER": "none",
    "OTEL_EXPORTER_OTLP_PROTOCOL": "http/protobuf",
    "OTEL_EXPORTER_OTLP_HEADERS": "Authorization=Bearer <token>",
    "OTEL_EXPORTER_OTLP_ENDPOINT": "http://127.0.0.1:4318"
  }
}

{{- else if eq . "codex-config"}}
[otel]
environment = "production"
log_user_prompt = false
exporter = { otlp-http = {
  endpoint = "http://127.0.0.1:4318/v1/logs",
  protocol = "json",
  headers = { "authorization" = "Bearer ${AI_USAGE_OTLP_TOKEN}" }
} }

{{- else if eq . "codex-token"}}
export AI_USAGE_OTLP_TOKEN='<token>'

{{- else if eq . "opencode-config"}}
{
  "plugin": [
    [
      "@devtheops/opencode-plugin-otel",
      {
        "enabled": true,
        "endpoint": "http://127.0.0.1:4318",
        "protocol": "http/protobuf",
        "otlpHeaders": "{env:AI_USAGE_OTLP_HEADERS}",
        "metricPrefix": "opencode.",
        "resourceAttributes": "deployment.environment=production",
        "disabledTraces": ["tool"]
      }
    ]
  ]
}

{{- else if eq . "opencode-token"}}
export AI_USAGE_OTLP_HEADERS='Authorization=Bearer <token>'

{{- else if eq . "copilot-settings"}}
{
  "github.copilot.chat.otel.enabled": true
}

{{- else if eq . "copilot-env"}}
OTEL_EXPORTER_OTLP_ENDPOINT=http://127.0.0.1:4318 \
OTEL_EXPORTER_OTLP_HEADERS='Authorization=Bearer <token>' \
code

{{- else if eq . "maki-config"}}
maki.setup({
    telemetry = {
        enabled = true,
        metrics_exporter = "none",
        logs_exporter = "otlp",
        protocol = "http/protobuf",
        endpoint = "http://127.0.0.1:4318",
        headers = { ["authorization"] = "Bearer <token>" },
    },
})
