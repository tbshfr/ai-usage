OTLP tokens

Each client sends one of these tokens as Authorization: Bearer <token> to the OTLP receiver, and its usage is attributed to that token. Group tokens (for example work and private) to compare usage per group, then filter the dashboard by group or by a single token. Once a token exists, every export must carry a valid token.
